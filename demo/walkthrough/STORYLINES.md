# Walkthrough storylines

Chosen: **Can I ship this change?** A developer asks Hermes to check a small Python repository. Real CLI capture carries the story from discovery through validation to an execution receipt. Matching Kujo/Hermes bumpers frame the evidence. This answers how to use the plugin with a concrete task.

Alternative: **Follow the receipt.** Begin with the real result, then reverse through each tool call to the original prompt. Strong evidence story, less direct onboarding.

Alternative: **One request, many tools.** A large prompt transforms into tool families, then resolves into a real result. Better overview, less time showing the host.

# Submission limits

The demo's three checkout checks prove that fixture's observed failure and correction. They do not prove general correctness. Receipt hashes detect changes to local evidence; they are not signatures or a universal release gate.

The model workflow is the original recorded Qwen3.5 4B session. The official release runtime was verified separately in unit, canonical-tool and native-host checks. Installation requires Hermes, official Kujo and Git; optional tools still need their own prerequisites. Recording waits are condensed and cached sources are disclosed.

The Git installation currently downloads the repository's tracked demonstration media as well as runtime source. The compact native ZIP is much smaller, but requires manual installation steps documented in `docs/releasing.md`. Moving heavy media to release assets is a future packaging improvement, not a new capability claimed by this submission.

The release tag and downloadable archives retain their original contents. The initial README used an unsupported tag value for `--ref`; current documentation and release notes correct it to a full commit SHA. The catalog candidate includes this documentation correction and has separate passing CI.

Public posting still needs a complete owner listening review and explicit authorization. The catalog PR, X post and form submission are not complete.

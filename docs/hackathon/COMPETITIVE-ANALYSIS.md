# Competitive analysis — November 9, 2026

Kujo is a credible technical entry, but breadth alone will not beat a plugin that demonstrates one useful outcome clearly. Chronos, Night Shift and Precedent Log have sharper stories. Warden overlaps substantially with the accountability positioning. The best response is to show a real defect found and corrected, with evidence a reviewer can inspect.

## Evidence standard and rules

This review checked the current official catalog, pinned competitor source trees, README disclosures and submission PRs. Selected implementation paths were inspected for Chronos, Night Shift, Precedent Log, phone plugins and other entries. Competitor tests were **not run**. Test counts and performance claims below remain author reports. Catalog acceptance does not prove hackathon eligibility, security or runtime reliability.

The [official catalog rules](https://github.com/NousResearch/hermes-agent/blob/main/plugin-catalog/README.md) and [submission guide](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins/catalog-submission) require a public, loadable plugin, exact source pin, matching capabilities, disclosures and validation. These were directly inspected. The current stable release was [Hermes 0.23.0](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.0), commit `2bd378ed1b8d6bf2192cb26e0a55ff3091e6bd19`.

The full hackathon announcement was verified on [Nous Research's official LinkedIn company feed](https://kn.linkedin.com/company/nousresearch) on November 9. It confirms the four criteria—usefulness, reliability, polish and creativity—and preference for functionality beyond prompts or skills. Submission closes November 11 at 5 PM EST. Entrants need a catalog PR, a public X demo tagging @NousResearch, and both links in the official form. The video must be under 90 seconds and show working behavior. The organizer explicitly permits form submission once the PR is open; do not wait for merge. [The matching official X post](https://x.com/NousResearch/status/2118094256438936062) returned 403, though its oEmbed attribution was accessible. The [form](https://form.typeform.com/to/FwJLvOln) itself could not be inspected, so additional fields and consent terms remain unverified.

An exceptional entry gives a judge a concrete problem, a working outcome, an understandable boundary and reproducible proof. A long tool list establishes none of those by itself.

## Recommended competitive response

Lead with the checkout defect: a discount causes a $5.99 overcharge. Show the actual assertion, the small correction, the same checks passing and the two receipts. This is concrete enough for a non-Kujo developer and technically defensible.

Keep installation to one short shot with prerequisites visible. Keep Spec and Eval central. Mention PackWrite, Scout, ShipCheck and optional execution tools only after the outcome is clear. Do not claim automatic global enforcement, rollback, signed attestation, all tools installed, or unique accountability. Our defensible advantage is a common native boundary for existing engineering tools, reviewed execution and inspectable evidence across a workflow. A prompt can ask for tests; it cannot itself provide the plugin's registration, approval binding, bounded process lifecycle and persistent receipt implementation.

Source pins and capability disclosures were captured November 9. Recheck changed PRs before submission; this is not a complete security audit of competitors or a prediction of the judges' preferences.
